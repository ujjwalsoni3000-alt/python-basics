# Data Structures

| Structure | Syntax | Ordered | Mutable |
|-----------|--------|---------|---------|
| list | `[1, 2]` | yes | yes |
| tuple | `(1, 2)` | yes | no |
| dict | `{"a": 1}` | yes | yes |
| set | `{1, 2}` | no | yes |

## Files
- `examples.py` : runnable examples
- `exercises.py` : practice problems
