# Getting Started

Python is a beginner-friendly programming language used for web development, data science, automation, and more.

## Install Python
Download it from https://www.python.org/downloads/ and check the install with:

```bash
python --version
```

## Run your first program
```bash
python hello_world.py
```

## Files
- `examples.py` : runnable examples
- `exercises.py` : practice problems
